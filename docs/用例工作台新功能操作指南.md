# 用例工作台新功能操作指南

本文档说明 **采纳率、生成统计、我的知识库、快照对比、质量检查** 等功能的使用方法，内容与现网页面（2026-06-10 起）一致。

**入口：** Hugo Feng Toolkit → **用例工作台**（`/tool/test-cases`）→ **AI 生成** Tab

**文档位置：** 项目仓库 `docs/用例工作台新功能操作指南.md`

---

## 一、功能总览

| 功能 | 入口位置 | 是否需要登录 |
|------|----------|--------------|
| 采纳率批次条 | **列表 / 导图** 用例生成成功后，工具栏下方蓝色条 | 否 |
| **生成统计** | 蓝色批次条 **「生成统计」**（生成用例后出现） | **否**（未登录存浏览器）；**是**（登录存服务器） |
| 质量检查 | 蓝湖工具条 **「质量检查」开关**；生成后浮窗可再次打开 | 否（AI 对照需蓝湖 Cookie + URL） |
| 快照对比 | 暂存列表每行「对比」；批次条 **「快照对比」** | 否（本机暂存） |
| 我的知识库 | 蓝湖区 **「我的知识库」** | **登录**：账号持久化 + 本机草稿；**未登录**：本浏览器 |

## 二、采纳率

### 2.1 什么时候出现？

1. 应用表头模板  
2. 填写提示词，点击 **「列表用例生成」** 或 **「导图用例生成」**  
3. 生成成功且解析出至少 1 条用例  
4. 工具栏下方出现 **蓝色批次条**

> **导图说明：** 导图生成成功后，用例 **仅写入思维导图视图**，**不会自动同步到表格**。批次条可记录本批次采纳率（全部采纳/拒绝）；行级 ✓/✕ 采纳仅适用于列表视图。导图与表格数据相互独立，不会自动同步。

### 2.2 批次条操作

- **全部采纳** / **全部拒绝**  
- **生成统计**：查看近 30 天汇总（见下文）  
- **快照对比**：与最近暂存或当前表格对比（需先有暂存）  
- **✕ 关闭**：关闭批次条  

> 采纳率进度条 **仅作参考**，便于感知本批次质量；与导出等功能无强制绑定。

### 2.3 单行操作

**列表生成：** 表格每行左侧 **✓** 采纳 · **✕** 拒绝  
编辑某行并保存 → **编辑后采纳**；删除某行 → **拒绝**

**导图生成：** 无表格行级采纳，请用批次条 **全部采纳/拒绝** 记录本批次态度。

### 2.4 采纳率计算

```
采纳率 =（采纳 + 编辑后采纳 + 导出采纳）÷ 本批次生成行数
```

## 三、生成统计

### 3.1 入口

- 蓝色批次条 **「生成统计」**（列表/导图生成成功后出现）

### 3.2 数据存在哪里？

| 登录状态 | 存储位置 | 说明 |
|----------|----------|------|
| **未登录** | **本浏览器** `localStorage` | 清除站点数据、换浏览器或无痕模式后 **历史统计清空** |
| **已登录** | **服务器（您的账号）** | 换设备登录同一账号仍可查看近 30 天趋势 |

### 3.3 合并本地历史

未登录时产生的 **生成统计与采纳率** 保存在本浏览器。登录时系统会 **可选提示「合并本地历史」**，您可选择：

- **合并**：将本机暂存、统计批次、知识库草稿同步到账号  
- **暂不**：本机数据仍保留，不影响已登录功能  

已登录后，打开 **生成统计** 弹层，若仍有未同步的本机批次，可点击 **「合并本地历史」** 手动同步。

> 合并为 **可选操作**，不会自动覆盖或删除账号已有数据。

### 3.4 统计内容

- 近 **30 天** 各批次：时间、列表/导图、预设/自定义、是否用 RAG、生成行数、采纳率  
- 汇总：批次数、总生成行数、总采纳率

## 四、我的知识库

### 4.1 打开方式

蓝湖工具条 **「我的知识库」** → 右侧抽屉。

### 4.2 登录与未登录

| 状态 | 行为 |
|------|------|
| **已登录** | 上传/粘贴保存在 **账号** 下（每账号最多 20 篇，单篇约 12 万字），并 **同步本机草稿备份** |
| **未登录** | 保存在 **本浏览器** `localStorage`，**刷新后仍可继续编辑** |

### 4.3 抽屉内操作

上传 md/txt · 粘贴需求 · 勾选参与生成 · 删除  

须 **已配置蓝湖需求** 时，勾选的个人文档才会注入生成上下文。

### 4.4 与 RAG 召回

- **公共 RAG**：解锁密码并打开 **「RAG召回」**  
- **个人文档**：在知识库中勾选

## 五、列表与导图数据隔离

| 操作 | 数据写入 |
|------|----------|
| **列表用例生成** | 仅右侧 **表格** |
| **导图用例生成** | 仅 **思维导图** |
| **表格 → 导图**（FAB） | 将表格内容转为导图 |

两套数据 **默认隔离**，避免互相覆盖；仅在您主动点击转换按钮时跨视图同步。

## 六、质量检查

1. 蓝湖工具条打开 **「质量检查」**（生成前打开 → 生成后自动检查）  
2. 或生成后点右下角 **「质量检查」** 浮窗  
3. 抽屉展示：**可能胡编** / **可能遗漏** / **格式问题**  

**前提：** 表格有用例行；AI 对照须先填蓝湖 Cookie + URL，建议先 **预览摘要** 确认可拉取。

---

## 七、蓝湖预览摘要（预设 / 自定义）

| 模式 | 操作 |
|------|------|
| **预设** | 填 `lanhu-cookie`、`lanhu-url` → **预览摘要** |
| **自定义** | 填 `custom-lanhu-cookie`、`custom-lanhu-url` → **预览摘要** |

成功时显示「已整理 xxx 字」，用于当次生成与质量检查。

## 八、快照对比（Diff）

暂存列表 **「对比」** 或批次条 **「快照对比」**（需至少 1 条暂存）。  
标记：**新增** / **删除** / **修改**。

---

## 九、推荐工作流

```
1. 选模板 → 填蓝湖 Cookie + URL → 预览摘要（确认当次需求可拉取）
2. （可选）登录 → 合并本地历史 / 将历史需求放入我的知识库
3. （可选）解锁并打开 RAG召回
4. 打开「质量检查」开关
5. 列表 / 导图用例生成
6. 批次条：采纳 → 生成统计 / 快照对比
7. 暂存 → 导出 Excel / XMind
```

## 十、常见问题

**Q：生成统计为空？**  
A: 需先完成至少一次「列表/导图用例生成」并在批次条关闭前有过采纳操作；未登录时勿清除浏览器站点数据。

**Q：未登录的统计能带到登录后吗？**  
A: 登录时会提示 **「合并本地历史」**（可选）；也可在已登录状态下打开生成统计，点击 **合并本地历史**。选择「暂不」时本机记录仍保留。

**Q：导图没有批次条？**  
A: 确认已解析出 TC 用例；导图成功后会显示批次条，但不会自动写入表格。

**Q：导图生成后表格是空的？**  
A: 属预期行为。导图与表格数据相互独立，请使用表格视图单独编辑或导入。

**Q：未登录知识库刷新后丢了？**  
A: 2026-06-10 起未登录文档会写入本浏览器草稿，刷新后应可恢复。若仍丢失，请检查是否清除了站点数据。
