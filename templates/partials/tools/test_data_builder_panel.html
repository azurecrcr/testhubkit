使用说明与合规限制

                
            

            

                
工具用途：面向已获得授权的测试、联调或预发环境，按 JSON 字段路径递增数值并批量代发 HTTP 请求，用于构造测试数据。请勿将本工具用于未获许可的第三方生产系统。

                
频率与域名限制（平台策略）：

                
    
                    
  • 目标 URL 命中常见正规平台主域（如阿里、腾讯、字节、百度、京东、美团、银行、运营商等）时，单次「请求次数」最多 {{ tdb_protected_max_repeat|default(5) }} 次，以降低对公共服务的异常压力。
    • 
                    
  • 其它地址单次「请求次数」最多 {{ tdb_max_batch|default(500) }} 次；可通过「间隔(ms)」适当拉长请求间隔。
    • 
                    
  • 多个递增字段时，可在「递增范围与请求次数」弹窗中为各字段单独设置范围；当某字段「上限 − 下限」小于请求次数时可勾选循环；未开启循环时可勾选不携带，递增到上限后后续请求不再附带该字段。
