Test Hub Kit 隐私政策

更新日期：{{ legal_updated }}　｜　生效日期：{{ legal_updated }}

Test Hub Kit（以下简称「本平台」）深知个人信息对您的重要性，并会尽力保护您的个人信息安全。本《隐私政策》说明我们如何收集、使用、存储、共享与保护您的个人信息，以及您如何行使相关权利。请您在使用本平台前仔细阅读。您注册、登录或使用本平台服务，即表示您已理解本政策所述内容。

本政策依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等适用法律法规制定。

一、我们如何收集和使用个人信息

我们仅会出于下列与提供服务直接相关的目的，收集和使用您的个人信息。若需将信息用于本政策未载明的其他用途，我们将再次说明并征得您的同意（法律法规另有规定的除外）。

1.1 账号注册与登录

  • 注册须使用手机号并通过短信验证码完成实名核验；邮箱地址可在注册后于个人资料中绑定，用于登录与账号安全验证；
  • 登录密码（加密存储）、短信/邮箱验证码、图形验证码相关信息；
  • 昵称、头像等您主动填写的资料信息；
  • 用于维持登录状态的会话标识（Cookie / Session）。

上述信息用于创建与核验账号、履行实名核验义务、保障登录安全、提供账号服务。历史仅邮箱注册且尚未绑定手机号的用户，须在继续使用业务功能前完成手机号绑定。

1.2 核心业务功能

  • 您在用例工作台、用例管理、缺陷管理、压测造数、文档工具等模块中主动输入、上传、导入或生成的内容（如需求摘要、用例、缺陷、评论、附件、场景配置、运行记录等）；
  • 您连接第三方需求工具（如蓝湖）时提供的必要凭证与拉取的需求相关数据（以您主动操作为前提）；
  • 您创建的评审分享链接及其评论内容；
  • 站内消息、团队邀请与成员协作相关信息。

上述信息用于实现您选择使用的功能、保障协作与导出分享、改进服务体验与安全风控。

1.3 AI 相关功能

  • 为完成生成、智能编辑、质量检测等请求所必需的提示词、上下文、附件及模型返回结果；
  • 您自行配置的个人 AI / Agent 密钥（用于调用您指定的服务，平台会采取合理保护措施）；
  • 免费额度使用情况等计量信息。

若您使用平台内置模型，相关请求可能为完成服务而被处理；若您使用自有密钥，数据处理还可能适用相应第三方服务商规则。

1.4 服务运营与安全

  • 设备与日志信息：如浏览器类型、访问时间、大致网络环境、操作日志、错误日志等；
  • 用于防刷、防滥用的验证码与频率限制相关信息；
  • 您通过「投稿 / 建议」提交的反馈内容及可选联系方式。

上述信息用于保障网络安全、排查故障、处理投诉建议及打击滥用行为。

1.5 无需征得同意的情形

根据法律法规，在下列情形下处理个人信息不必征得您的同意，例如：为订立或履行您作为一方当事人的合同所必需；为履行法定职责或法定义务所必需；为应对突发公共卫生事件，或紧急情况下保护自然人生命健康和财产安全所必需；在合理范围内处理您自行公开或其他已经合法公开的个人信息；法律法规规定的其他情形。

二、Cookie 与同类技术

我们使用 Cookie 或同类技术保存登录状态、记住必要偏好，并提升安全性与可用性。您可通过浏览器设置管理 Cookie，但停用后可能导致部分功能（如保持登录）无法正常使用。

三、我们如何共享、转让、公开披露个人信息

3.1 我们不会向第三方出售您的个人信息。

3.2 在以下情形中，我们可能共享必要信息：

  • 服务必要的委托处理：如短信验证、邮件发送、云基础设施、内容安全等供应商，我们会要求其按约定处理并保护信息；
  • 您主动选择的第三方：如您配置的 AI 模型服务商、您连接的蓝湖等第三方平台；
  • 协作对象：当您邀请成员、分享评审链接或开展团队协作时，相关内容可能对您指定的对象可见；
  • 法律责任：根据法律法规、诉讼、仲裁或行政主管机关的强制要求。

3.3 如发生合并、分立、收购、资产转让等，个人信息转移将依法告知，并要求继受方继续受本政策约束；否则我们将重新征得您的授权同意。

3.4 我们不会公开披露您的个人信息，除非获得您的单独同意或法律法规另有规定。

四、我们如何存储和保护个人信息

4.1 我们在中华人民共和国境内存储您的个人信息。如确需向境外提供，将依法履行告知、评估、标准合同等合规义务并征得必要同意。

4.2 我们仅在实现本政策所述目的所必需的最短期限内保留个人信息，法律法规另有规定或为实现审计、争议解决、安全风控所必需的除外。超出期限后，我们将删除或依法匿名化处理。

4.2.1 为履行网络安全与审计义务，与账号认证、登录尝试、安全风控相关的日志（含登录成功/失败记录、验证码发送相关记录及桌面端认证审计等），留存时间不少于 180 天；超出留存期限后将删除或依法匿名化处理。

4.3 我们采取合理可行的安全措施，包括访问控制、传输与存储保护、权限管理、安全审计等，防止个人信息遭到未经授权的访问、披露、使用、修改、损坏或丢失。

4.4 请理解，任何安全措施都无法做到绝对安全。如发生个人信息安全事件，我们将依法启动应急预案，并按要求告知您或向监管部门报告。

五、您的权利

在符合法律法规的前提下，您对自己的个人信息享有以下权利：

  • 查阅、复制：您可在个人资料等页面查看部分信息，或通过反馈渠道申请查阅、复制；
  • 更正、补充：您可在相关页面自行修改昵称、头像、绑定信息等，或联系我们协助处理；
  • 删除：在法定情形下，您可请求删除相关个人信息；
  • 改变授权同意范围：您可停止使用相关功能或撤回同意；撤回不影响撤回前基于同意已开展处理活动的效力；
  • 注销账号：您可通过「投稿 / 建议」申请注销；注销后我们将依法删除或匿名化您的个人信息，法律法规要求保留的除外；
  • 响应说明：我们将在核实身份后的合理期限内处理您的请求；对明显重复、超出合理范围或法律法规另有规定的请求，可能依法予以拒绝并说明理由。

六、未成年人保护

本平台主要面向具备完全民事行为能力的成年人。如您为未满十八周岁的未成年人，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本平台。我们不会主动收集未成年人的个人信息；如发现在未获监护人同意的情况下收集了相关信息，我们将尽快删除。

七、第三方服务说明

本平台可能包含跳转或对接第三方网站、产品与服务。该等第三方有其独立的隐私政策与用户条款，建议您在使用前仔细阅读。除法律法规另有规定或我们另有约定外，第三方对其服务中的个人信息处理独立承担责任。

八、本政策如何更新

我们可能适时修订本政策。更新后的政策将在本页面发布，并注明更新日期。对于重大变更，我们会通过更显著的方式提示。若您在政策更新后继续使用本平台，即表示您已了解更新后的政策；如您不同意，请停止使用并可通过反馈渠道联系我们处理账号。

九、如何联系我们

如您对本政策或个人信息保护有任何疑问、投诉或建议，请通过本平台顶部导航「投稿 / 建议」与我们联系。我们将在核验后尽快答复。
