## 用例工作台

**入口**：https://testhubkit.com/tool/test-cases  
（别名：`/tool/test-case-generator`）

面向测试设计的 AI 辅助工作台：列表表格与思维导图双形态，适合写用例、评审、导出，并可把成果导入团队用例库。

### 主要能力

| 能力 | 说明 |
|------|------|
| **AI 列表用例生成** | 按提示词流式生成结构化表格（模块、步骤、预期等）；支持覆盖 / 追加 / 取消 |
| **AI 导图用例生成** | 生成思维导图形态，适合评审拆解 |
| **表格 ↔ 导图** | 表格视图与导图视图切换；可把 AI 表格结果转为思维导图（含流式） |
| **蓝湖需求树** | 连接蓝湖 Cookie，拉取文档树；按需求页配置提示词并生成用例；文档可本地管理 |
| **RAG 召回** | 生成时可结合知识召回（企业/私有化场景；站点侧可配置开关） |
| **智能编辑侧栏** | 对话式改表；支持附件（PNG/JPG/WebP/PDF/TXT）；可撤销；保留近期会话 |
| **质量检测** | 独立按钮触发 LLM 流式校验，可关闭结果面板 |
| **覆盖率分析** | 对生成/编辑结果做覆盖相关分析 |
| **Excel 导入导图** | 导入已有用例表，转为可编辑导图 |
| **导出 Excel** | 列表视图导出结构化用例表 |
| **用例评审分享** | 生成分享链接；协作者打开只读预览：`/share/tc/<token>` |
| **按需求持久化** | 登录后可将表格用例 / 导图 JSON 按需求页保存 |
| **批量操作** | 行/表头批量操作（FAB），便于整理大批量生成结果 |

### 使用提示

- **列表**适合导出、行级精修与导入用例管理；**导图**适合评审展示。两视图能力互补，请按目标选形态。
- 未登录可试用生成与浏览；蓝湖持久化、分享、云端会话、导入团队库等需登录。
- 生成受站点 AI 配额与模型配置约束；可在账号菜单配置个人 API Key，或使用管理员配置的全站模型。

### 典型流程

1. （可选）连接蓝湖 → 选需求页 → 配提示词 / RAG → 生成  
2. 表格精修或智能编辑 → 质量检测 → 导出 Excel / 转导图 / 创建评审分享  
3. 登录后在「用例管理」从工作台导入，进入团队执行闭环

## 用例管理

**入口**：https://testhubkit.com/tool/case-management  

**需登录。** 与「用例工作台」独立：工作台偏 AI 设计与产出；用例管理偏**团队用例库、执行与测试计划**。

### 项目与协作

- 多项目管理（创建 / 编辑 / 删除）
- 成员邀请、接受 / 拒绝；站内消息通知；成员搜索添加
- 目录（Suite）树：子目录、「全部用例」

### 用例库

| 能力 | 说明 |
|------|------|
| **CRUD** | 新建 / 编辑 / 删除用例；标题搜索；优先级、状态筛选；分页 |
| **批量** | 改状态、移动目录、复制、删除、登记执行 |
| **手工执行记录** | 单条或批量登记执行结果 |
| **目录 Schema** | 锁定列结构、模板、重置；导入时字段映射 |
| **从工作台导入** | 选取工作台产物，预览 schema 映射后入库 |
| **Excel 导入** | 上传预览 → 确认导入 |
| **Excel 导出** | 可按目录范围导出 |
| **回收站** | 个人隔离；恢复；到期自动清理；可彻底删除 |

### 测试计划与质量闭环（需项目团队）

- **测试计划**：新建计划、分配用例与执行人、批量执行登记  
- **发布门禁（Gate）**：计划发布 / 取消发布  
- **质量统计**：项目执行与质量概览  
- **操作日志**：审计轨迹，可导出 CSV  
- **用例详情 → 建缺陷**：一键联动缺陷管理  

### 典型流程

1. 登录 → 建项目 → 邀请成员（建议 ≥2 人以便开缺陷板）  
2. 从工作台或 Excel 导入用例 → 建目录整理  
3. 建测试计划 → 分配执行 → 登记结果 →（失败）创建缺陷

## 缺陷管理

**入口**：https://testhubkit.com/tool/defect-management  

**需登录**；需先在用例管理创建项目，并组成**至少 2 名正式成员**的团队后使用。

### 主要能力

| 能力 | 说明 |
|------|------|
| **缺陷列表** | 按项目查看；状态侧栏筛选（待处理 / 已确认 / 处理中 / 已解决等） |
| **新建与编辑** | 标题、描述、优先级、严重程度、指派处理人（**当前不支持附件**） |
| **关联用例** | 搜索并关联用例管理中的用例 |
| **评论** | 缺陷下评论（分页） |
| **成员** | 与项目成员体系一致，可管理 / 邀请 |
| **导出** | 支持 CSV 等审计导出能力 |
| **消息跳转** | 指派、状态变更等可通过消息中心 deep link 直达 |

### 与用例管理的关系

- 缺陷挂在**同一项目**下  
- 可从用例执行失败路径创建并回链用例  
- 适合「设计（工作台）→ 入库（用例管理）→ 执行 / 计划 → 缺陷」一条链

## 压测造数工作台

**入口**：https://testhubkit.com/tool/api-scenario-studio  

同一页面 Tab 切换 **JMeter 压测** 与 **HTTP 批量造数**，无需本机安装 JMeter 即可可视化搭场景。

### JMeter 压测

`?tab=jmeter`（默认）

| 能力 | 说明 |
|------|------|
| **树形可视化编排** | 测试计划 → 线程组（SetUp / 主流程 / TearDown）→ HTTP 请求与各类元件 |
| **元件卡片** | 定时器、断言、监听器、逻辑控制器（If / 循环 / 事务等）、配置元件 |
| **配置元件** | HTTP 默认值、Header / Cookie / Cache Manager、CSV 数据集、计数器等 |
| **挂载区** | 在 HTTP 请求、Debug 取样器、逻辑控制器下添加子元件 |
| **双模式编辑** | 可视化编辑 + YAML 高级模式 |
| **导入** | curl、YAML Step、`.jmx`（前端解析，有大小限制） |
| **导出** | 校验配置 → 生成结果（JMX + README）→ 下载 ZIP；亦可导出 YAML 供本地 / CI |
| **并发配置** | 线程数、Ramp-Up、持续时间 / 循环；Influx scenario 标签 |
| **监控对接** | 可配置被测地址与 Influx Backend Listener，对接 Grafana 等看板 |
| **模板与暂存** | 内置模板（如全元件全景、搜索链路）；场景保存 / 列表 / 恢复 |
| **AI 步骤助手** | 悬浮助手流式生成或改写步骤（step-plan / step-edit 等） |

本地 JMeter：导出 JMX 后用本机或 CI 执行即可。

### HTTP 批量造数（数据构建）

→ https://testhubkit.com/tool/api-scenario-studio?tab=data  

- 配置 URL、Method、Token、Headers / Body  
- **递增字段**与次数上下限，批量发请求  
- curl 导入；查看生成的 Python / cURL  
- 结果日志与 TXT 下载  
- 为压测准备账号、Token、业务数据

## 常见问题

**未登录能用吗？**  
能试用用例生成、媒体工具、浏览压测与多数界面；用例管理 / 缺陷、消息同步等需登录。

**用例工作台和用例管理有什么区别？**  
工作台 = AI 设计与产出（表格 / 导图 / 蓝湖 / 分享）；用例管理 = 团队用例库、执行、计划与导入导出。可先工作台生成，再导入管理。


**压测场景能在本地 JMeter 跑吗？**  
可以，在压测造数工作台导出 JMX 后用 JMeter 或 CI 执行。

**缺陷管理为什么进不去？**  
需登录，并在用例管理中建好项目且有足够正式成员（通常 ≥2 人）后再打开缺陷板。

**AI 用不了或配额不够？**  
检查是否登录、是否配置个人 / 全站模型 Key；配额耗尽时站点会提示。私有化可对接自有模型服务。

**反馈渠道？**  
站内「投稿或建议」、交流群，或 GitHub Issues。
